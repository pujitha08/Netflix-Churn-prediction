Project Idea: Netflix (Customer Retention and Churn)
Problem Statement:
Streaming platforms such as Netflix face increasing competition and high customer acquisition
costs. Retaining existing subscribers has become a strategic priority. Identifying which factors
drive churn and loyalty will enable Netflix to reduce customer attrition and improve personalized
recommendations.
Research Questions:
Logistic Regression:
·
What customer behaviors (e.g., watch time, genre preference, frequency of use)
predict subscription churn?
Cluster Analysis:
·
Can customers be segmented into distinct groups based on their viewing and
subscription patterns?
Moderation Analysis:

Which features contribute increase/decrease the effect of churn on each other?
Analytical approach:

Perform logistic regression
Cluster analysis using the user database
Explore moderation analysis on how various features contribute to the effect of churn
Data Source:
Kaggle datasets on Netflix viewing patterns, ratings, and churn
